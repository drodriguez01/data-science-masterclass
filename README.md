# Data Science Masterclass

Repositorio práctico para la enseñanza de Ciencia de Datos utilizando Python y R.

El objetivo de este proyecto es mostrar el flujo completo de análisis de datos:

1. Carga de datos
2. Exploración inicial
3. Limpieza y preparación
4. Análisis descriptivo
5. Visualización de resultados

# Dataset utilizado

## Superstore Sales Dataset

El proyecto utiliza un dataset comercial con información de ventas:

- Clientes
- Productos
- Categorías
- Regiones
- Ventas
- Ganancias
- Descuentos

Archivo:
datasets/superstore.csv

# Ejercicios

## Python

### 01 - Exploración

Objetivo:

Conocer la estructura del dataset.

Conceptos:

- DataFrame
- filas y columnas
- tipos de datos
- estadísticas básicas

### 02 - Limpieza

Objetivo:

Preparar datos para análisis.

Conceptos:

- valores faltantes
- duplicados
- conversión de fechas
- creación de variables

### 03 - Análisis

Objetivo:

Responder preguntas de negocio.

Ejemplos:

- ventas por categoría
- ganancias por región
- mejores productos
- mejores clientes

### 04 - Visualización

Objetivo:

Comunicar resultados mediante gráficos.

Conceptos:

- gráficos de barras
- gráficos de dispersión
- interpretación visual
