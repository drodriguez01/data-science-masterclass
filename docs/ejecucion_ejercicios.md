# Ejecución de los Ejercicios

## Descripción

Este documento explica cómo ejecutar los ejercicios desarrollados en Python y R.

Todos los comandos deben ejecutarse desde la carpeta raíz del proyecto.

---

# Verificar ubicación

Antes de ejecutar cualquier ejercicio, comprobar que se encuentra en la raíz del repositorio:

```bash
pwd
```

Ejemplo:

```text
/home/usuario/data-science-masterclass
```

---

# Ejecutar ejercicios en Python

## Ejercicio 1 - Exploración

```bash
python3 exercises/python/01_exploracion_superstore.py
```

Este ejercicio muestra:

- Primeros registros
- Dimensiones del dataset
- Columnas disponibles
- Tipos de datos
- Estadísticas descriptivas

---

## Ejercicio 2 - Limpieza

```bash
python3 exercises/python/02_limpieza_superstore.py
```

Este ejercicio realiza:

- Identificación de valores faltantes
- Identificación de registros duplicados
- Conversión de fechas
- Creación de la variable de días de entrega

---

## Ejercicio 3 - Análisis

```bash
python3 exercises/python/03_analisis_superstore.py
```

Este ejercicio calcula:

- Ventas por categoría
- Ganancias por región
- Top 10 productos
- Top 10 clientes

---

## Ejercicio 4 - Visualización

```bash
python3 exercises/python/04_visualizacion_superstore.py
```

Este ejercicio genera gráficos para analizar:

- Ventas por categoría
- Ganancias por región
- Relación entre ventas y ganancias

---

# Ejecutar ejercicios en R

```bash
Rscript exercises/r/03_analisis_superstore.R
```

---


---

# Recomendaciones

- Ejecutar los ejercicios en el orden propuesto.
- Comparar los resultados obtenidos en Python y R.
- Modificar el código para experimentar con nuevos análisis.
- Utilizar Visual Studio Code para facilitar la edición y ejecución de los archivos.

---

# Flujo recomendado

1. Clonar el repositorio.
2. Instalar las dependencias.
3. Ejecutar los ejercicios de exploración.
4. Continuar con la limpieza de datos.
5. Realizar el análisis de información.
6. Finalizar con la visualización de resultados.
