# Estructura del Proyecto

## Descripción

Este repositorio contiene ejercicios prácticos para el curso **R y Python para Ciencia de Datos**. Los ejercicios utilizan el dataset **Superstore** y están organizados de forma que permitan comparar el desarrollo de un mismo análisis en ambos lenguajes.

---

# Organización de los ejercicios

Los ejercicios siguen el mismo flujo de trabajo en ambos lenguajes:

1. Exploración de datos.
2. Limpieza de datos.
3. Análisis de información.
4. Visualización de resultados.

Esto permite comparar fácilmente la sintaxis y las herramientas disponibles en Python y R para resolver un mismo problema.
